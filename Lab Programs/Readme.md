# Internet Programming Lab — Experiments 01–25

25 separate browser-based front-end mini-projects based on the first 25 experiment descriptions in the supplied lab manual.

## Run
1. Extract the ZIP.
2. Open any `qXX_.../index.html` file in a modern browser.
3. Each experiment has its own `app.js`; shared responsive styling is in `assets/style.css`.

## Included
- Experiments 01–25, each in its own folder.
- Searchable sample records, add-record forms, status updates, quick actions and JSON export.
- Browser-local persistence via `localStorage`; use **Reset** to restore sample data.

## Scope
These are compact, client-side lab implementations. They demonstrate interface flow and basic JavaScript behavior. Authentication, server-side database storage, payment gateways, OTP, email/SMS, live maps, QR scanning and real-time availability are not connected. Do not use the voting, medical, insurance or payment demonstrations with real personal data.
